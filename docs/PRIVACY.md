# Public snapshot scope

This repository was assembled from an explicit allowlist: current application source, synthetic tests, local preview/check tools, English technical documentation, and existing brand assets.

## Excluded

- Private Git history, branches, tags, and repository configuration.
- Customer records, account information, databases, uploaded media, and local credentials.
- Internal requirements, operating manuals, deployment patches, installers, and infrastructure inventories.
- Private repository links and actual integration identifiers.

Contact details are demonstration values. The mini-program application identifier and filing reference have been replaced. Tests create their own temporary data; they do not use production records.

## Review boundary

Before publication, the selected files are inspected for credentials, identifiers, phone-like values, local paths, and unintended data files. Pattern scanning supplements file review; it is not a universal security certification.

Future contributions must follow the same boundary. Do not copy an entire private checkout or import private Git history to update this portfolio.
